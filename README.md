# Trek 650 — ملاح GPS

تطبيق ملاحة GPS بواجهة مستوحاة من أجهزة GPS المحمولة: خرائط تعمل بدون إنترنت، وكل صيغ إحداثيات جارمن (hddd°mm.mmm' و UTM و MGRS…)، واستيراد وتصدير GPX.

**افتح التطبيق:** https://almarre18.github.io/trek650/

على الآيفون: افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
